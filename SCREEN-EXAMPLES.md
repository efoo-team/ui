# 画面例の索引

`@efoo/ui` の画面例を、画面の型ごとに並べた索引です。画面例は、架空の販売管理サービスの画面で、エージェントが画面を作るときに「考え方ごと真似る」お手本です。

## 使い方

1. 作る画面に近い型を、下の表から選びます。
2. 「ソースのパス」のファイルを開き、`meta.parameters.docs.description.component` の説明文を読みます。説明文は、目的と読み手・情報構造・データパターン・情報の流れ・主役・抑えたもの・使わなかったもの・目的が違えば変わるところの 7 項目で、判断の理由の本文はここにだけ書いてあります。この索引の「主な判断」は、読む型を選ぶための 1 行の要約です。
3. 見た目ではなく判断を写します。説明文の 7 項目を自分の画面の目的に当てはめ、目的が違うところは「目的が違えば変わるところ」に従って変えます。
4. 見た目は[公開 Storybook](https://efoo-team.github.io/ui/) の「画面例」で見ます。story は `https://efoo-team.github.io/ui/?path=/story/<story の id>`、説明文付きの Docs は `https://efoo-team.github.io/ui/?path=/docs/<Docs の id>` で開けます。

画面例は、外枠（`stories/ScreenExamples/shared/AppFrame.tsx`）と架空データ（`stories/ScreenExamples/shared/data.ts`）を共有しています。`data.ts` の `OrderEvent` は閉じた union 型の `kind` を持ち、履歴の種類は表示文言ではなく `kind` で判定します。受注の状態の名前は「キャンセル済み」です。外枠を持たない画面（サインイン）を除き、どの画面例も同じ外枠の中に描かれます。

同梱したソースは、判断と部品の組み方を読むためのものです。そのまま動かすには、Storybook（`@storybook/react-vite`）、`@tabler/icons-react`、`@mantine/form`、`@mantine/notifications`、`@mantine/dates`、`@mantine/charts`、`@mantine/hooks`、`recharts`（`@mantine/charts` が使う）、`dayjs`（`@mantine/dates` が使う）と、`MantineProvider` に `efooTheme` と `efooCssVariablesResolver` を渡す設定（このリポジトリでは `.storybook/preview.tsx`。npm パッケージには入りません）が要ります。画面例の見た目は、すべてこの theme から来ています。

## 共有の部品

`stories/ScreenExamples/shared/` の下のファイルは、画面例のあいだで共有しています。

| ファイル               | 内容                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `AppFrame.tsx`         | 画面例すべてが共有する外枠です。組織の切り替えを持つサイドバー、ページの経路・全体検索・アカウントのメニューを持つヘッダーを描きます。画面は `parent`（サイドバーの項目）と `page`（その下の項目）を渡し、主領域の中身だけを書きます。選択中の組織は `defaultOrganization`、サイドバーの件数は `counts` で替えられ、保存していない変更を持つ画面は、`onBeforeNavigate` で移動を止められます。狭い幅ではサイドバーを Mantine の Drawer に入れ（`variant="sidebar"` で広い幅と同じ面と余白になり、自前のダイアログの処理は持ちません）、画面を移る項目は `component="a"` のリンクです（サービスでは router の Link に替えます）。組織の切り替えは `Menu.RadioGroup` と `Menu.RadioItem` で組みます。同じファイルの `SERVICE_NAME`（架空のサービス名「販売管理」）は、外枠を持たないサインインが見出しに使います。 |
| `SectionCard.tsx`      | 画面の 1 つのまとまりを、見出し付きの Card に入れます。見出しは h2 を h5 の大きさで表示し、見出しの下に任意で補足を 1 行置きます。見出しの右上の操作は `actions` で、Card の props も受けます。見出しのある Card は、ダッシュボードも含めてすべてこれで作ります。Card は見出しで名前が付いた section なので、スクリーンリーダーでまとまりの一覧から移動できます。                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `BackLink.tsx`         | 一覧の下にある画面のための「○○に戻る」のリンクです。ヘッダーのページの経路は `sm` 以上の幅でしか出ないので、それより狭い幅でだけ表示し、戻り先の一覧の名前を言葉にします。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `OrderLink.tsx`        | 受注番号を、受注の詳細へのリンクとして描きます。新しいタブで開け、Tab キーで届きます。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `OrderMenu.tsx`        | 受注の行の端にある操作のメニューです。項目は「納品書を印刷」と「受注をキャンセル」で、受注を開く項目は置きません（受注番号のリンクに一本化するため）。キャンセルできない受注では、「受注をキャンセル」を無効にして出し、メニューの形を保ちます。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `OrderStatusBadge.tsx` | 受注の状態の Badge です。対応が要る「未発送」にだけ注意の色を使い、ほかの状態は枠線だけで出します。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `data.ts`              | 画面例すべてが共有する架空データ（組織・顧客・商品・受注・問い合わせ）と、金額の書式などの補助関数です。「受注から 2 日以上たった未発送」の判定は `LATE_DAYS`（基準の日数）と `lateDays`（その日数以上待っている未発送の受注の経過日数を返し、そうでなければ返さない関数）の 1 か所にあり、ダッシュボードの件数と一覧の「受注から N 日」の Badge が共有します。名前・住所・数字はすべて架空で、画面が表す日付は 2026 年 10 月 31 日です。2 つ以上の画面に出る数字や、1 つの画面に 2 回出る数字は、同じ元の値から計算します。                                                                                                                                                                                                                                                                                    |
