# efoo UI

efoo のサービスで共通して使う Mantine の theme と、その theme を使った部品の表示例です。このリポジトリの目的、導入、使い方、ライセンスは、リポジトリの [README](https://github.com/efoo-team/ui/blob/main/README.md) にまとめています。

## 使い方

導入の手順と使い方の本文は README だけに置いているので、次の節を README で読んでください。

- [導入](https://github.com/efoo-team/ui/blob/main/README.md#導入): 入れるパッケージと、TypeScript の設定。
- [CSS の読み込み](https://github.com/efoo-team/ui/blob/main/README.md#css-の読み込み): Mantine と `@efoo/ui` の CSS を読み込む順と、サービスの CSS との優先順位。
- [MantineProvider](https://github.com/efoo-team/ui/blob/main/README.md#mantineprovider): `efooTheme` と `efooCssVariablesResolver` の渡し方。
- [ライトとダークの決め方](https://github.com/efoo-team/ui/blob/main/README.md#ライトとダークの決め方): ダークを持つか、切り替えを保存するか、保存先をどうするか。
- [日付・時刻の日本語設定](https://github.com/efoo-team/ui/blob/main/README.md#日付時刻の日本語設定): 日付・時刻を使うときの日本語ロケール。
- [日本語の折り返し](https://github.com/efoo-team/ui/blob/main/README.md#日本語の折り返し): 文節で折り返すための `lang` の指定と、はみ出す要素への対処。
- [サービスごとに調整する](https://github.com/efoo-team/ui/blob/main/README.md#サービスごとに調整する): theme・CSS 変数 resolver・variant の色をサービスで上書きする方法。
- [動き](https://github.com/efoo-team/ui/blob/main/README.md#動き): 視差効果を減らす設定と、通知の緩急。
- [Popover](https://github.com/efoo-team/ui/blob/main/README.md#popover): Popover の中で操作させるときの指定。
- [サイドメニュー](https://github.com/efoo-team/ui/blob/main/README.md#サイドメニュー): AppShell の navbar と NavLink で作るサイドメニューの規則。コード例は `stories/ScreenExamples/shared/AppFrame.tsx`。
- [shadcn/ui の variant との対応](https://github.com/efoo-team/ui/blob/main/README.md#shadcnui-の-variant-との対応): shadcn/ui の variant に当たる Mantine の指定、Text の variant、`sticky-actions`、Badge、グラフの色。
